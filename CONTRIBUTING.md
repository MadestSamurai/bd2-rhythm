# Contributing

Build and run tests with `./build.ps1 -Locked` on Windows and the .NET 8 SDK. Describe the problem, intended behavior and relevant checks in pull requests. For UI changes, check both languages and the minimum window size. For planner changes, use synthetic chart cases that exercise the behavior.

Do not commit game files, exported charts, recordings, credentials, account data or local diagnostics. Read [Development](docs/DEVELOPMENT.md) and retain third-party notices.
